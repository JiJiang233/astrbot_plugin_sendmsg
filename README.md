# astrbot_plugin_sendmsg

AstrBot 的 QQ 群发消息插件。管理员可以通过一个 `/sendmsg` 命令，控制当前 aiocqhttp（OneBot v11）Bot 向单个群、单个好友、全部群、全部好友或全部联系人发送消息。

## 环境要求

- AstrBot `>= 4.9.2, < 5`
- 消息平台：`aiocqhttp`（OneBot v11）
- 命令仅限 AstrBot 管理员使用

## 使用方法

| 命令 | 作用 |
| --- | --- |
| `/sendmsg <群号或QQ号>` | 自动识别目标并向单个群或好友发送 |
| `/sendmsg group all` | 向当前 Bot 的所有群发送 |
| `/sendmsg friend all` | 向当前 Bot 的所有好友发送 |
| `/sendmsg all` | 向当前 Bot 的所有群和好友发送 |
| `/sendmsg help` | 显示帮助 |

执行命令后，Bot 会在同一会话持续收集管理员发送的消息，支持 AstrBot/OneBot 消息链可发送的文本、图片等内容：

- 发送 `发送` 或 `send`：结束收集并开始群发。
- 发送 `取消` 或 `cancel`：终止操作。
- 只收集 1 条消息：保持原消息形式直接发送。
- 收集 2 条及以上消息：将这些消息按收集顺序合并成一条消息记录后发送。

每收到一条内容都会重新计算 120 秒等待时间。控制词必须作为一条纯文本消息单独发送。

数字 ID 会先与当前 Bot 的群列表、好友列表匹配。若某个数字同时是已加入的群号和好友 QQ 号，可用下面的明确写法消除歧义：

```text
/sendmsg group <群号>
/sendmsg friend <QQ号>
```

群发按目标逐个发送，并在两次发送之间保留短暂间隔。完成后会返回成功数和失败摘要；单个目标失败不会中断其余目标。

## 安全说明

- 插件命令使用 AstrBot 的管理员权限过滤器，普通用户无法调用。
- 群和好友列表从发起命令的当前 Bot 实例实时获取。
- 插件不写入持久化数据，也不生成临时配置文件。
- 请控制群发频率和内容，遵守 QQ/OneBot 服务端规则，避免账号风控。

## 安装

将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_sendmsg/`，然后在 WebUI 中重载插件。

## 版本

- `1.0.0`：实现单目标、全部群、全部好友和全部联系人群发；支持持续收集消息、单条直发、多条合并转发、取消、超时和失败汇总。
